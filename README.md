# Ricky Alimentos — Sitio web

Página web de **Ricky Alimentos**, proveedora de carnes en Saltillo, Coahuila.

## Estructura

- `index.html` — página principal (portada, nosotros, catálogo de productos sin precios, contacto con mapa y redes sociales).
- `css/styles.css` — estilos con los colores del logo (rojo `#E30613` y azul marino `#0B1464`).
- `js/main.js` — menú móvil, búsqueda y filtro por categoría del catálogo.
- `img/` — logo de Ricky Alimentos y logo de TFC.

## Ver el sitio

Abre `index.html` en el navegador, o publícalo con GitHub Pages
(Settings → Pages → rama `main`, carpeta `/root`).
